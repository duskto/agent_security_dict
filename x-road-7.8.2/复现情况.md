## 四、已验证结论（1 条）

### GHSA-2x2v-c43v-w789 — Central Server 机器凭据授权过度 / 信息读取越权

- **分层**：**已验证（低危）**；利用方式＝认证后 API 路径（需先持有 management-service API key）。
- **类型**：CWE-863 授权不当（**不是**认证绕过）。

**证据链（输入来源 / 校验逻辑 / 绕过条件 / 放行效果）**

1. **输入来源**：`cs` 容器 `/etc/xroad/conf.d/local.ini` 的 `[management-service] api-token = <redacted>`（`[registration-service]` 同值），经 `Authorization: X-Road-ApiKey token=<redacted>` 头进入 CS 管理 API（`https://192.168.98.x:4000`，远端可用）。
2. **校验逻辑**：从 `cs` 的 `centralserver-admin-service-1.0.jar` 内 `BOOT-INF/classes/permissions.yml` 一手提取，确认角色 `XROAD_MANAGEMENT_SERVICE` 被授予其职能不需要的读权限：
   - `VIEW_APPROVED_CAS: [XROAD_SYSTEM_ADMINISTRATOR, XROAD_MANAGEMENT_SERVICE]`
   - `VIEW_APPROVED_CA_DETAILS: [XROAD_SYSTEM_ADMINISTRATOR, XROAD_MANAGEMENT_SERVICE]`
   - `VIEW_VERSION: [XROAD_SYSTEM_ADMINISTRATOR, XROAD_SECURITY_OFFICER, XROAD_REGISTRATION_OFFICER, XROAD_MANAGEMENT_SERVICE]`
   - 该角色本职权限为 `ADD_*_REQUEST` / `IMPERSONATE_SECURITY_SERVER` 等 management-request 类。
3. **绕过条件**：非“绕过”，而是“**过度授权**”（角色权限超出职能所需）。
4. **调用方放行效果（实测，从攻击机直接 HTTP）**：带该 key 时

   | 请求 | 结果 |
   |---|---|
   | `GET /api/v1/certification-services` | **200** → `[{"id":1,"name":"Test CA", …}]` |
   | `GET /api/v1/system/status` | **200**（`node_name=node_0`，HA 未配置，初始化状态） |
   | `GET /api/v1/system/version` | **200** → `{"info":"7.8.2"}` |
   | `GET /api/v1/initialization/status` | **200**（`instance_identifier=test`、`central_server_address=cs`、token 已初始化） |
   | `GET /api/v1/notifications/alerts` | **200** → `[]` |

   **反证/对照**：无 Authorization → 401；错误 key → 401；`Authorization: Bearer <key>` → 401；`GET /api/v1/clients` → **403**。说明授权层为逐权限判定、非 fail-open，200 是“权限被授”而非“校验被绕过”。

**独立 verdict gate 结论**：**保留为“已验证（低危）”**，但必须标注**前置＝已持有 management-service API key**，定性为“授权过度 / 信息读取越权”，**不得表述为认证绕过**；影响上限为读取诊断/系统/trust 元数据，无写入、无密钥/配置泄露证据。

**未闭合点（供后续如需升格时补证）**：
- 未做 `ApiWebSecurityConfig` 的一手阅读（“key→角色”映射一段目前依据公告转述）。
- 未证明 management/registration-service 组件**从不需要**这些 VIEW 权限（“超出职能所需”现依据公告 + 权限表对比）。
- 未证明存在**本不该持有该 token 的其他主体/主机**实际持有它；本环境中该 token 只存在于 CS 自身。

## 五、危险配置 / 辅助条件

- `local.ini` 中 `[management-service]` 与 `[registration-service]` **共用同一明文 token** → 凭据卫生问题，**不作为独立漏洞**。
- 本环境 proxy 进程启动参数含 `-Djavax.xml.accessExternalDTD=""` / `-Djavax.xml.accessExternalStylesheet=""` → 对 `GHSA-7m7r`（XXE）构成 JVM 级缓解（已验证为缓解配置；未做实证利用）。
