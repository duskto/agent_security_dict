## 六、候选与反证

### P1 内置 PostgreSQL 5432 对外 TCP 开放 —— 危险配置（**非漏洞**）
- 事实：`postgresql.conf: listen_addresses = '*'`；iptables 放行 `5432`；外部 TCP 可连。
- **反证（实测）**：从攻击机发送 PostgreSQL `StartupMessage`，服务端返回
  `FATAL 28000 … "no pg_hba.conf entry for host \"192.168.101.x\", user \"postgres\", database \"postgres\", no encryption"`。
- `pg_hba.conf` 实际仅 `local` / `127.0.0.1/32` / `::1/128` 的 `trust` 规则，**无任何远程网段规则** → 远程连接在认证层被拒。**放行效果未闭合 ⇒ 独立不可利用。**
- 保留价值：`trust` 覆盖本机回环 —— **若**未来在本机出现 SSRF / 代理类原语，可作**利用链辅助条件**，但本轮不成立。

### P2 root SSH `PermitRootLogin=yes` + `PasswordAuthentication=yes` —— 危险部署状态（**非产品漏洞**）
- `sshd -T` 实测：`permitrootlogin yes`、`passwordauthentication yes`、`permitemptypasswords no`。
- 属运维/部署配置，与产品 CVE 无关；口令由用户侧掌握。**不得表述为认证绕过/漏洞**。

### P3 组件库版本（合并为**单一**“待验证假设”，不拆成多条）
- 版本清单（一手）：`snakeyaml 1.30`、`netty 4.1.101.Final`、`tomcat-embed 9.0.83`、`jackson-databind 2.13.5`、`spring 5.3.31 / spring-boot 2.7.18`、`spring-security 5.7.11`、`log4j-api 2.17.2`（**无 `log4j-core`**）、`commons-collections 3.2.2 / 4.1`、`postgresql-jdbc 42.3.8`、`hibernate-core 5.6.15`。
- 判断：**未发现任何一条具备“未认证可达 + 可触发”的入口证据**；`log4j-api` 无 `log4j-core`，Log4Shell 不适用；`commons-collections`/`snakeyaml` 缺反序列化/不可信 YAML 入口证明。
- 分级：**待验证假设 / 利用链辅助条件**。**无入口证据前不得升格，也不得因“库版本旧”包装成漏洞。**

### P4 h4dm / tunnel(TNexus) / lwdproxy 为自研或半自研服务 —— **负证据（观察项，非结论）**
- 未检索到这些组件在本版本上的公开 CVE 或公开 PoC（NVD 中 `tnexus` 命中为无关产品 `dtp.ae tNexus Airport View`）。
- “未检索到” ≠ “不存在”；该条只支持“**无公开已知漏洞**”，不能支撑“无漏洞”。

## 八、结论分层（经独立 verdict gate 复核后收敛）

**核心主结论（拆分为两条，均带限定）：**

1. **无适用的公开 CVE**：目标实际 build `4.7.4-305be35` **高于** VCDA 唯一公开 CVE（`CVE-2024-22277`，VMSA-2024-0016）的官方修复版本 `4.7.2` ⇒ 版本层面判定不受影响。**属版本推断，未做补丁 diff / 编码点验证。**
2. **在当前未配置状态与本次评估边界内，未发现可复现的未认证远程漏洞。**

**关键限定（必须随主结论保留）：**
- replicator 的对外 HTTP 面（80/443/8043/8440）被 **全局 `ServiceNotConfigured` 拦截**（任意路径/任意方法）→ 其**未认证攻击面在本状态下不可评估**；“不存在漏洞”不能由该状态反推。
- tunnel API（8442/8047）为统一的 401 认证门控；h4dm（3030）提供 Web UI 与 405 的 API 根，**本轮未做深度逆向**。

**降为旁支：** P1、P2 → 危险配置 / 端口暴露；P3 → 单一“待验证假设”条目；P4 → 负证据观察项。

**无需进入升格**：无候选具备“输入来源 / 校验逻辑 / 绕过条件 / 调用方放行效果”四段闭环证据链。

## 九、危险配置 / 辅助条件（均不作为漏洞结论）

- root SSH 允许口令登录（P2）；root 口令为环境共享值。
- `listen_addresses='*'` + iptables 放行 5432（P1）；远程被 `pg_hba` 拒绝。
- 暴露面端口较多且非默认：`8440 / 8442 / 8047 / 8048 / 3030 / 44045 / 44046`。
- `ServiceNotConfigured` 使 replicator 攻击面不可评估（环境阻塞，非“安全”证据）。
