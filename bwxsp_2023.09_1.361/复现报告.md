## 五、危险配置 / 观察项（均不作为漏洞结论）

1. **`7120` 对外可达，与产品自带要求不符（已实测确证）**
   - 产品规则 `/usr/local/broadworks/XSP_Rel_2023.09_1.361/conf/iptables_rules` 明确要求：
     `! -i lo -p tcp --dport 7120 -j DROP`（**非 lo 一律丢弃**）。
   - 实测**该限制未落地**：`iptables -P INPUT ACCEPT`（无相关规则）；`nft list ruleset` 无 7120 规则；`firewall-cmd --zone=broadworks --list-all` → `target: ACCEPT`、`ports:` 空。
   - 实际暴露面：`7120` = `bwMoDaemon.socket` → 每连接 `stunnel`（`ExecStart=/usr/bin/stunnel .../stunnel.conf`，`User=bwadmin`）。
   - **反证（重要，防止误判为漏洞）**：`stunnel.conf` 中 `verify = 4` + `CAfile = .../modaemon.cert` → **强制客户端证书（mTLS）**；实测无客户端证书时握手以
     `sslv3 alert handshake failure (SSL alert number 40)` 结束 → **未认证不可利用**。
   - 分级：**危险配置（深度防御缺失）**，非独立漏洞。若某处泄露 `modaemon` 客户端证书，则该端口将变为可利用，故仍建议按产品要求补齐 lo-only 规则。
2. **`2240/2340/2400`（BCCT）对 `0.0.0.0` 开放**：产品规则文件对这三个端口**没有任何限制**（仅约束 7120），即“按产品设计但依赖网络边界”。本轮**未做协议逆向**，`2240`（unsecured）的认证要求**未验证** → 记「观察项 / 待验证」。
3. **SSH 弱口令**：`root` 账号允许口令登录，且口令为弱值（由用户提供）→ 部署风险（非产品漏洞）。
4. 产品自带的 `7120` 限制规则未生效，提示该机的 BroadWorks 防火墙档位（firewalld `broadworks` zone）**可能未按产品方式生成**——值得与本 lab 其他 BroadWorks 设备横向对比（需另行授权）。
