## 二、条目 1（**已验证**，pre-auth）：未认证暴露的 AWS 控制面（moto S3 模拟）

> **认证边界：pre-auth** —— 全部请求无 `Authorization` 头、无 Cookie、零凭据。
> 影响：匿名获取桶名与**全部对象键**（泄露内部卷路径与模块命名）、匿名读取 moto 管理面状态导出；对象级 `GET` 被前置网关拒绝（403），因此**未取到对象内容**；但 `PUT` 被接受（匿名写入），配合保留绕过可删除对象。

### 2.1 请求证据（全部未认证）

| 请求 | 响应 |
|---|---|
| `GET /` | **200** `application/xml` `Server: amazon.com` → `ListAllMyBucketsResult`，桶 `windmill-volumes` |
| `GET /windmill-volumes?list-type=2` | **200** → 匿名列出 2 个对象键（含内部卷路径 `volumes/demo/libvol/...`） |
| `GET /moto-api/data.json` | **200**，13974–15124 B → 匿名导出 mock 后端全量状态，服务键 `['cloudwatch','core','events','iam','s3','sts']` |
| `GET /moto-api/` | **200** → 匿名访问 moto 管理 UI |

### 2.2 对象级权限矩阵（经前置 Werkzeug 网关）

| 方法 | 结果 | 说明 |
|---|---|---|
| `GET /windmill-volumes/<已知存在的 key>` | **403**（`text/html`，0 字节） | 读被网关拒绝 ⇒ 对象内容未泄露 |
| `GET /windmill-volumes/nonexistent` | 403 | 存在的与不存在的同样 403 ⇒ **非 404/403 差分，无存在性预言机** |
| `PUT /windmill-volumes/audit-probe.txt`（11 字节） | **200** | **匿名写入被接受**，随即出现在对象清单中 |
| `DELETE /windmill-volumes/audit-probe.txt` | **403** | 被"治理保留（Object Lock / governance retention）"拦下 |
| 同上 + `x-amz-bypass-governance-retention: true` | **204** | **保留保护被绕过，对象被删除** |

> ⇒ 结论：**匿名可写 + 可用保留绕过头删除** = 可对数据存储做写入/篡改；读取侧被网关挡住，故当前**未构成完整的数据泄露**。

### 2.3 反证与未闭合点

- **反证已排除**：`/moto-api/data.json` 中 `AccessKey` / `AssumeRole` / `Token` 等字段**均为空数组**，全量 dump 中**未检索到任何 AccessKeyId / SecretAccessKey / SessionToken / 口令**（正则命中 0 处）⇒ 未泄露云凭据。
- 未闭合：① 对象内容读取（受 403 阻断）；② moto 版本号；③ 后端是否另有关联服务（仅 5000 暴露）；④ 匿名写入的真实影响范围（该机性质判断为基准测试载体）。
- 处置：**已按最小可证明原则只做 1 次 PUT 探针，并在同一轮内删除**，复核对象清单已还原为原始 2 个（见 §三）。
