# Ivanti Connect Secure 22.6R2.1（192.168.188.x）— 复现报告

> 记录类型：**设备级复现报告**（含 **2 条同一利用链的漏洞级动态复现**：`cve-2023-46805-auth-bypass/` + `cve-2024-21887-command-injection/`）。
> 口径：严格以「实际运行版本 + 实际补丁状态 + 真实可达利用链」为准。

## 一、归属定案与访问形态

| 项 | 观测 |
|---|---|
| 目标 | `192.168.188.x` |
| 台账登记 | viptela-vbond（20.18.2.1）→ **与实测不符，标注台账过期/待和解** |

## 二、实际版本（一手证据）

**结论：`IVE-OS 22.6R2.1`，build `2487`，硬件型号 `ISA-V`，运行于 VMware 虚机。**

来源：借助认证绕过（CVE-2023-46805）读取的 `/api/v1/system/system-information`（详见漏洞记录）：

```json
{"software-inventory":{"software":{"build":"2487","name":"IVE-OS","version":"22.6R2.1"}},
 "system-information":{"hardware-model":"ISA-V","host-name":"localhost2","hypervisor":"VMware",
 "os-name":"ive-sa","os-version":"22.6R2.1","serial-number":"VASPHZJ28X359RKAS"}}
```

> 注：登录页本身不暴露版本号（`grep` 无版本/版本串）；版本经认证绕过取得，已交叉印证设备归属。

## 五、结论分层

- **高置信候选 / 黑盒已验证**：**CVE-2023-46805 + CVE-2024-21887 组合 ⇒ 未认证命令执行（uid=0/root）**（高价值 pre-auth、真实网络攻击路径）。
- **可推导能力（未直接演示）**：任意文件读（以 `grep -q` 条件探测演示命中/不命中，未回读文件内容）。
- **归属定案**：本机 = Ivanti Connect Secure（台账 vBond 条目作废）。
