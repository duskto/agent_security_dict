# Evidence 05 — 未认证 RCE 动态执行（真实网络路径，单 TCP 连接，无凭据）

## 失败路径（保留作反证）
# (a) 直接取 AllThreads 的线程 id 去 InvokeMethod：
[-] invoke on 0x1c (Session-HouseKeeper-...) failed: JDWP error 10 (cs=3 c=3)   # INVALID_THREAD
[-] invoke on 0x9  (Log4j ... WatchDog)      failed: JDWP error 10
[-] invoke on 0xb  (Tomcat JDBC Pool Cleaner) failed: JDWP error 10
[-] ... 全部线程均 error 10
    => 不能复用 AllThreads 的 id；JDWP 对象 id 随目标线程对象回收而失效。
# (b) 断点 suspendPolicy=SUSPEND_ALL(2)：InvokeMethod 无应答（超时，且全 VM 冻结 ~60s，随后 Resume 恢复）。
    => 该 JVM 上必须用 SUSPEND_EVENTTHREAD。
